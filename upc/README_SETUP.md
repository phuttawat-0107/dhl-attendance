# DHL UPC Attendance Lite — คู่มือตั้งค่า (ทำครั้งเดียว ~20 นาที)

ระบบนี้แยกจากระบบ BKK/NAT เดิม 100% (โปรเจกต์ Firebase ใหม่) — ข้อมูลเดิมไม่ถูกแตะ

| ไฟล์ | หน้าที่ |
|---|---|
| `upc/staff.html` | แอปลงเวลาสำหรับสาขา (หัวหน้าสาขาถือเครื่อง) |
| `upc/manager.html` | หน้า Manager (UPC เห็นเฉพาะสาขาตัวเอง / Admin เห็นทั้งหมด + จัดการระบบ) |
| `upc/fb.js` | ตัวเชื่อม Firebase + โหมดทดลอง |
| `upc/firestore.rules` | กฎความปลอดภัย (วางใน Firebase) |

> ทดลองก่อนได้เลยโดยไม่ต้องตั้งค่าอะไร: เปิดลิงก์ท้ายด้วย `?demo`

---

## ขั้นที่ 1 — สร้างโปรเจกต์ Firebase ใหม่
1. เข้า https://console.firebase.google.com → **Add project** → ตั้งชื่อ เช่น `dhl-upc-attendance`
2. Google Analytics → **ปิด** ได้ → Create project

## ขั้นที่ 2 — เปิด Firestore
1. เมนูซ้าย **Build → Firestore Database → Create database**
2. Location: **asia-southeast1 (Singapore)** ⚠️ เปลี่ยนภายหลังไม่ได้
3. เลือก **Production mode** → Create

## ขั้นที่ 3 — วางกฎความปลอดภัย
1. Firestore → แท็บ **Rules**
2. ลบของเดิมทั้งหมด → วางเนื้อหาไฟล์ `firestore.rules` ทั้งไฟล์ → **Publish**

## ขั้นที่ 4 — เปิดระบบล็อกอิน
1. **Build → Authentication → Get started**
2. แท็บ Sign-in method → **Email/Password** → Enable (ข้อแรกอย่างเดียว) → Save
3. แท็บ **Settings → User actions** → ✅ Enable create (sign-up) (ต้องเปิด เพราะ Admin สร้างบัญชีสาขาจากหน้า Manager)

## ขั้นที่ 5 — เอาค่าเชื่อมต่อมาใส่ในแอป
1. ⚙️ **Project settings → General → Your apps → ไอคอน `</>` (Web)** → ตั้งชื่อ `upc-web` → Register
2. จะเห็นก้อน `firebaseConfig = { apiKey: ..., authDomain: ..., ... }`
3. **ส่งก้อนนี้มาให้ Claude** (ค่าเหล่านี้ไม่ใช่รหัสผ่าน ปลอดภัยที่จะอยู่ในหน้าเว็บ) → Claude จะใส่ใน `fb.js` แล้วอัปโหลดให้

## ขั้นที่ 6 — ให้ระบบลบรูปเก่าอัตโนมัติ (TTL)
1. Firestore → แท็บ **TTL** (หรือ Time-to-live) → **Create policy**
2. Collection group: `photos` · Timestamp field: `expireAt` → Create
3. รูปที่เกิน 31 วันจะถูกลบเอง (แอป Staff มีตัวลบสำรองอีกชั้นอยู่แล้ว)

## ขั้นที่ 7 — สร้างบัญชี Admin ของคุณ
1. เปิด `upc/manager.html` → จะขึ้นหน้า **ตั้งค่าครั้งแรก** (ขึ้นครั้งเดียวตลอดอายุระบบ)
2. ตั้งชื่อผู้ใช้ + รหัสผ่าน (≥ 8 ตัว) → ได้บัญชี Admin ทันที

## ขั้นที่ 8 — ขยายทีละ Manager (ทำซ้ำได้เรื่อย ๆ)
1. แท็บ ⚙️ แอดมิน → **➕ เพิ่มสาขา** (หรือ 📥 เพิ่มหลายสาขา วางจาก Excel: รหัส · ชื่อ · ภาค · จังหวัด)
   → ระบบสุ่ม PIN ให้ → กด “คัดลอกทั้งหมด” ส่งให้หัวหน้าสาขา
2. **➕ เพิ่ม Manager** → เลือกสาขาที่ดูแล → คัดลอกชื่อผู้ใช้/รหัสผ่านส่งให้ UPC
3. หัวหน้าสาขาเข้า `staff.html` → แท็บ 👥 รายชื่อ → 📥 นำเข้า Excel (รหัส · ชื่อ · Vendor · 2W/4W) → เริ่มลงเวลาได้ทันที

## ค่าใช้จ่าย (ประเมิน 130 สาขา × ~20 คน)
| รายการ | ต่อเดือน | ฟรี (Spark) |
|---|---|---|
| รูป 30 วัน (~30 KB/รูป) | ~2–2.5 GB ค้างในระบบ | 1 GB ❌ |
| เขียนข้อมูล | ~5,500 ครั้ง/วัน | 20,000/วัน ✅ |
| อ่านข้อมูล | ~10,000–30,000/วัน | 50,000/วัน ✅ |

- **ช่วงแรก (≤ ~50 สาขา) ใช้ฟรีได้**
- เกิน ~50 สาขา → อัปเกรดเป็น **Blaze** (ต้องผูกบัตร — คุณต้องทำเอง) ค่าใช้จ่ายคาดว่า **ไม่ถึง 50 บาท/เดือน**
- ตอนอัปเกรด ตั้ง **Budget alert** ที่ 100 บาท: Google Cloud Console → Billing → Budgets & alerts

## เรื่องที่ควรรู้
- **รีเซ็ต PIN สาขา** → เครื่องที่ใช้ PIN เก่าหลุดทันที ข้อมูลไม่หาย
- **ลืมรหัสผ่าน Manager** → Admin กด 🔑 รหัสผ่านใหม่
- **เน็ตหลุด** → ลงเวลาได้ตามปกติ ระบบส่งเองเมื่อมีเน็ต (เก็บในเครื่องแม้ปิดแอป)
- **บังคับอัปเดต** → หลังแก้แอป Admin กด 🔄 ในแท็บแอดมิน ทุกเครื่องรีโหลดเอง
- **เวลา 07:10** แสดงเฉพาะหน้า Manager (โหมด 🔒) — แอปสาขาเห็นแค่ 07:00
- **วันอาทิตย์** ไม่นับในรายงาน On-time
- ⏱ ธง “เวลาเครื่องต่าง” = เวลาในมือถือไม่ตรงกับเวลาเซิร์ฟเวอร์เกิน 5 นาที (อาจมีการแก้นาฬิกาเครื่อง) — ควรตรวจสอบ
